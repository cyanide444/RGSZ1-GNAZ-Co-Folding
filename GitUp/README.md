# GNAZ·RGSZ1 complex — structure modeling and analysis (Part 1)

Co-folding of the human **Gαz (GNAZ)·RGSZ1 (RGS20)·GTP·Mg²⁺** complex with AlphaFold3
(Boltz-2, via Neurosnap), analysis of the predicted interface, and comparison of the
active site to the RGS4·Gαi1 transition-state crystal structure **1AGR**.

> This repository contains **only Part 1** — the co-folding and the structural/sequence
> analysis. Nothing from the protein–protein docking (HADDOCK) portion of the project is
> included here.

## Numbering conventions (important)

| Entity | In the model files | Human canonical | Notes |
|--------|--------------------|-----------------|-------|
| **GNAZ** (chain A) | 1–355 | 1–355 (UniProt **P19086**) | full length. Switch I **175–188**, Switch II **200–220**, Switch III **228–240**; α-helical domain ≈ 63–174. |
| **RGSZ1** (chain B) | 1–117 | **262–378** (UniProt **O76081**) | chain B is the RGS-domain fragment only. **human = file + 261**. |
| RGSZ1 ↔ RGS4 mapping | file residue | RGS4 = **file + 61** | used to assign Tesmer et al. RGS-box helices. |
| **Catalytic residue** | RGSZ1 file **Ser67** | human **Ser328** | occupies the position of **RGS4 Asn128** — an Asn→Ser substitution that is diagnostic of the RZ subfamily. |

**1AGR** is a **rat** structure (Gαi1 P10824, RGS4 P49799); rat and human orthologs are
≥97% identical and identical at every residue discussed, so the rat/human distinction does
not affect any conclusion.

## Environment / reproducibility

- **Python 3** with **numpy** and **matplotlib** (figures were made with matplotlib 3.9).
- **UCSF ChimeraX 1.11** — used for hydrogen-bond detection (`addh` + `hbonds`, relaxed
  default 0.4 Å / 20° criteria) and Matchmaker superposition.
- **Sequences** were retrieved from UniProt (`curl https://rest.uniprot.org/uniprotkb/<ACC>.fasta`).

**Paths:** the scripts were run in place and contain **absolute Windows paths** (a `DIR=…`
or similar constant near the top of each file). To re-run from this repository, point those
constants at the copies provided here — model files are in `Structures/`, sequence FASTAs in
`Inputs/Sequences/`, and `scores.json` in `Inputs/`. The ChimeraX H-bond tables
(`hb_rank*.txt` / `hb_cif*.txt`) that `reassess.py` / `regen_cif.py` consume are
regenerated by running `chimerax_hbonds.cxc`.

## Suggested order to reproduce
1. `chimerax_hbonds.cxc` → `hb_rank{1,2,3}.txt` (ChimeraX).
2. `reassess.py` / `regen_cif.py` → `common_contacts_filtered.csv` (see **README_contacts.md**).
3. `plot_scores.py` → confidence plots (see **README_confidence.md**).
4. `align_1agr.py`, `contacts_1agr.py`, `map_helices.py`, `ts_analysis.py` → 1AGR comparison
   (see **README_1AGR_comparison.md**).
5. `ident.py`, `heatmaps.py`, `rgsfig.py`, `gz_gi_rat_fig.py`, `seqfig.py` → sequence figures
   (see **README_sequence_analysis.md**).
